1. Debes de bsucar siempre los siguientes elementos en el software que construyas:
- Escalabilidad
- Legilibilidad
- Codigo reutilizable
- Planteamiento arquitectonico estable
2. Debes seguir como principios de diseno de software los principios SOLID, buscando el cumplimiento de los principios pese a que no estes usando el paradigma orientado a objetos. Usandolo como tu forma de entender el proyecto, busca siempre que se respeten los principios SOLID.
3. Como arquitectura debes buscar implementar Clean Architecture, buscando que cada uno de los modulos que disenes tenga una responsabilidad y se refiera a un componente del sistema y resuelva unicamente un problema en el software.
4. Debes buscar las soluciones computacionalmente mas eficientes sin vulnerar las reglas anteriores, de forma que tu codigo debe ser eficiente, y no debe repetir logica.
